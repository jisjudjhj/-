# 大数据电商系统

基于“大数据分析 + 个性化推荐 + 电商交易闭环”设计的一体化项目，包含微信小程序用户端、Vue 3 管理端、Spring Boot 后端、实时计算链路、离线分析脚本与部署配置。

这个仓库适合以下场景：

- 电商推荐系统课程设计 / 毕业设计
- 大数据与实时计算项目展示
- 微信小程序电商项目二次开发
- 管理后台、推荐中台、实时看板的综合演示

当前公开仓库已经做过脱敏处理：

- 服务器账号、数据库密码、小程序私有配置不随仓库发布
- 本地私有环境文件已加入忽略规则
- 可直接作为公开展示仓库继续维护

## 项目简介

项目围绕“用户浏览商品 -> 推荐召回与排序 -> 加购/下单/支付/退款 -> 行为回流 -> 后台分析与策略调优”这条主线展开，既包含完整交易功能，也包含推荐、实时指标、用户画像、分群分析、风险控制等偏中后台能力。

相比单纯的商城项目，这个仓库更强调：

- 推荐链路：曝光、点击、加购、下单、支付、退款等行为回流
- 数据能力：实时聚合、离线分析、用户分群、效果看板
- 管理能力：管理员 / 商家双角色后台
- 演示能力：适合做课程答辩、作品集展示、比赛项目说明

## 核心能力

### 1. 用户小程序端

小程序目录：`user-miniprogram---2/user-miniprogram---2`

当前用户端已覆盖的页面与业务主线包括：

- 首页推荐
- 秒杀频道
- 探索页 / 分类浏览
- 商品详情
- 搜索结果页
- 购物车
- 结算页
- 订单列表 / 订单详情
- 评价与退款申请
- 个人中心
- 收藏、足迹、地址、消息、设置、钱包
- 客服与聊天
- AI 助手入口

小程序整体定位是“电商交易 + 推荐体验展示”，重点突出：

- 推荐内容呈现
- 商品浏览与转化路径
- 下单与售后闭环
- 用户个人中心与互动能力

### 2. 管理端 / 商家端

管理端目录：`management-pc`

当前 PC 端基于同一套 Vue 3 前端，根据账号角色切换管理员与商家视图，主要包括：

- 管理驾驶舱 / 工作台
- 商品、订单、用户、评价、退款管理
- 分类、Banner、优惠券、广播消息管理
- 秒杀活动管理
- 风险控制中心
- 推荐预览、推荐分析、AB Test 面板
- 用户画像、用户分群、大数据分析
- 实时流式看板
- AI 管理与智能辅助页面
- 商家端商品、订单、客服、评价、营销与店铺信息页

适合用于演示“运营后台 + 数据后台 + 推荐后台”三位一体的系统结构。

### 3. 后端服务

后端目录：`backend`

后端提供完整的电商业务接口与中后台能力，主要覆盖：

- 用户认证、注册、验证码、JWT 登录态
- 商品、分类、购物车、订单、退款、评价
- 优惠券、消息、地址、钱包
- 秒杀业务
- 文件上传与对象存储
- 推荐服务与推荐事件回流
- 实时指标接口
- 用户分群与分析任务触发
- AI 服务接入
- 风险控制、限流、角色权限
- WebSocket 实时推送

## 快速启动

### 1. 安装根目录工具依赖

```bash
npm install
```

### 2. 启动管理端前端

```bash
cd management-pc
npm install
npm run dev
```

默认开发地址：

- `http://localhost:5173`

### 3. 启动后端

```bash
cd backend
mvn spring-boot:run
```

或打包后运行：

```bash
mvn clean package -DskipTests
java -jar target/ecommerce-recommendation-1.0.0.jar
```

### 4. 小程序端

使用微信开发者工具打开：

```text
user-miniprogram---2/user-miniprogram---2
```

仓库中的 `project.config.json` 已使用公开占位配置，实际联调时请在你本地填写自己的小程序私有配置。

## 根目录常用命令

```bash
npm run bootstrap
npm run smoke
npm run analytics:run
npm run audit:mini
npm run seckill:test
npm run register:load-test
```

对应用途：

- `bootstrap`：项目基础初始化辅助脚本
- `smoke`：基础联通性检查
- `analytics:run`：执行分析任务脚本
- `audit:mini`：巡检小程序交易 / 推荐链路
- `seckill:test`：秒杀并发测试
- `register:load-test`：注册接口压测

## 实时链路与大数据能力

实时与流式相关内容位于：`streaming`

支持两类使用方式：

- 本机 Flink 直连 MySQL 的轻量实时聚合
- MySQL CDC -> Kafka -> Flink -> Redis / 后端接口 的增强链路

主要面向这些数据场景：

- 用户行为分布统计
- 用户类目偏好聚合
- 商品热度实时更新
- 推荐核心指标实时看板
